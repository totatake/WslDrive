# 定量評価・検証レポート一覧 (`docs/reports/`)

本ディレクトリには、時点ごとのベンチマーク比較、I/O スループット計測、トレース解析、およびリリース前の実機検証レポートを `YYYY-MM-<topic>.md` または `<topic>.md` 形式で配置します。

## レポート作成時の必須項目

1. **計測環境と再現条件**: Commit SHA、日時、Windows 11 ビルド番号、WSL2 バージョン、CPU/メモリ/ストレージ、ビルドプロファイル（`Release` 等）。
2. **再現コマンド**: 計測や検証に使用した具体的なコマンド・`scripts/` 内スクリプト。
3. **定量結果・比較表**: Before / After や方式間（ネイティブ `wsl --mount` vs NBD ブリッジ等）の比較。
4. **所見と次のアクション**: 具体的なボトルネック解析および [roadmap.md](../roadmap.md) への反映。
